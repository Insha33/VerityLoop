# VerityLoop Marketing Site

The marketing page for VerityLoop, an AI product decision system for founders and product teams.

## Run locally

```bash
npm run serve
```

Open [http://localhost:4173](http://localhost:4173).

## Test

```bash
npm test
```

The site is a dependency-free static frontend built with semantic HTML, modern CSS, and vanilla JavaScript. The waitlist form currently uses a simulated success state until a production endpoint is supplied.
